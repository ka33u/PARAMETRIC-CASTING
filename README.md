## 简易参数化三维（2026-09-26）

首页已改为「选款式 → 输入 3～5 个主尺寸 → 查看完整三维和重量」。六大类、十八种款式覆盖端盖、电机机座、轴承盖、法兰／环件、接线盒／盖与水冷机座。筋、耳、脚、法兰和铸出孔通过开关选择；其他尺寸按模板比例联动，需要时展开修改。

- 双击 `启动铸衡.command`，或在服务已运行时打开 `http://127.0.0.1:4179/`。关闭启动窗口不影响服务。

- 模板值、手动填写值与单独覆盖的细节可区分。修改主尺寸会自动带动未覆盖的细节，可随时恢复联动。
- 自动保留当前浏览器中的有效草稿，各类别切换可保留各自草稿。重要款式用“保存方案”命名复用；支持参数 JSON 备份／导入、STL（mm）与可打印 HTML 重量清单。
- “图纸与高级工具”保留原有 DWG／DXF、EXB 编目、图片与自定义截面功能。两种页面的方案格式不同，不混用。
- 毛坯／加工后口径只标记输入尺寸所属口径，不自动添加余量。灰铸铁密度默认 7.2 g/cm³，可修改。细节比例为通用预设，并非由 Y2／YE4 原图逐件识别。

三维与重量取自同一封闭实体，附属材料先求并集，孔仅扣除与材料相交部分，分项体积去重后合计等于整体。详细校验记录见 [42 组独立三维校验](docs/三维校验/说明.md)；最大体积差约 0.01004%，不代表实际铸件估重误差。

新界面源码在 `parametric/`。`npm ci && npm run build` 重建浏览器脚本，`python3 tools/build_offline.py` 生成单文件版，`python3 tools/build_bundle.py` 生成分发包。已固定依赖版本并附开源许可。`npm test` 共 97 项通过，包括原有工具与参数化实体回归、新增水冷模型验证。

### 水冷机座

新增环形水套、轴向隔水筋、环向隔水筋三个母模型，只填外径、定子腔内径、总长和内外筒壁厚。封水环、隔水筋与管座尺寸默认联动，可展开修改。进入水冷类别自动半剖；“水套空腔”显示蓝色空腔，便于核对。

水套净容积与净厚单独显示，水不计入铸件重量。进出水口有“无 / 实心管座 / 铸出水孔”三种状态，估算毛坯时避免误扣后续钻孔。底脚和法兰可选，未启用底脚时隐藏底脚孔选项。开启“两端法兰”后直接显示 A / B 两端轴向宽度，可分别输入；三维标记与分项重量区分两端。法兰宽度计入机座总长，不改变封水环厚度或水套有效长。两端径向伸出仍在细节中统一设置。旧方案的共用法兰厚度自动带入两端。

新增 [18 组水冷机座独立校验](docs/水冷机座校验/说明.md) 全部通过，铁与空腔最大体积差均约 0.011%。另有 [3 组不等宽端部法兰复算](docs/水冷机座校验/两端法兰/说明.md) 通过。模板按整体灰铸铁结构计算；分体异材外套需分别计算，隔水筋示意不代表完成冷却性能设计。

“底脚与支架”已从类别栏取消，但旧参数文件和旧保存方案仍可读取，避免丢失已有数据。

## 图纸与高级工具

## 原始 CAD 与本地图纸库（2026-09-24）

已对用户指定的两套资料建立只读索引：`/Volumes/kakku's disk/上海电科所 Y2` 和 `/Volumes/kakku's disk/YE4图纸-`。原文件不改动、不上传。本地图纸库按系列、类别、机座号和关键词筛选，无需每次在文件选择器里翻目录。磁盘未连接时仍可手动导入文件。

总资料为 Y2 的 954 DWG + 3 EXB、YE4 的 583 EXB。当前按名称和目录筛出 **413 份候选**：Y2 253 DWG、YE4 160 EXB，含毛坯与加工对照图，并非全部都是已确认灰铸铁件。可疑材料会从图内文字提示；例如实测一张接线盒盖为铸铝／铝合金。

### 使用步骤

1. 在“从原始图纸计算”中导入 DWG / DXF，或从图纸库点选文件。首次使用另一台电脑时先运行 `准备CAD组件.command`；本 Mac 依赖已装好。
2. 在画布中滚轮缩放、拖动平移，单击所需材料内部。原生填充区域优先选择，空洞保留；再次点击取消，Alt + 单击切换重叠候选。灰色背景表示原生填充，橙色为选区，绿色为计算实际采用的材料。
3. 回转件点选轴线或两点定轴。计算只取轴线一侧，并对多块选区求并集；相同上下半剖面不会直接相加。安装耳、偏心孔和未剖筋板需另算，正视图不可直接绕轴旋转。
4. 未指定单位的旧图需输入“每图形单位 = mm”，或填写已知实际长度后两点标定。图签 1:2 / 1:3 **不自动当作模型比例**；局部放大图要单独标定。还需核对选的是毛坯还是加工轮廓，括号外为毛坯、括号内为加工后。
5. 筋板、底脚、接线盒等可切换“选区面积 × 净厚度”，输入厚度和数量。净材料区域可带孔；追加只增减独立净体积，不做三维相交去重。
6. 核对材料、比例和剖面后计算，得到**所选结构估重**。新建会替换当前模型；追加可增减局部体积，同次结果不能重复追加。CAD 回转轮廓可载入最多 600 个积分段，复杂段默认折叠。
7. 完成主体、筋板和孔槽后，用“保存当前计算方案”导出 JSON，后续载入复用。方案包含参数和文字来源，不包含原图、CAD 画布选区或图像识别任务。

### 范围和兼容性

- 本地 DWG → DXF 转换 + 二维解析，支持块、曲线、闭合轮廓和原生 HATCH。圆弧以默认 0.02 图形单位／按文件单位换算的弦差近似；比例标定后实际误差应相应换算。
- 针对旧 Y2 图补充 DASHDOT 中心线、Unicode 直径符号、空模型空间的单布局直接几何，以及异常三维曲线／SHX 符号跳过提示。多布局、视口投影、缺口、外部参照、实体 3D 模型不自动还原。
- 能读取图形不等于自动理解整件。不能自动判断所有筋板数量、视图关系、毛坯余量及轮廓中的材料归属；用户必须核对这些信息。解析跳过对象会显示说明，不应忽略。
- **EXB 当前只能编目，尚不能直接解析或估重。** 可由 CAXA 官方支持的批量转换功能导出 DWG / DXF 后接入；没有导出件时不能承诺完整自动计算。官方说明：[CAXA CAD 电子图板](https://cad.caxa.com/pc/function2d)。
- CAD 文件上限 30 MB；解析在限时子进程中执行。缓存只保留最近 4 张图纸，2 小时后重新导入。图纸处理走本机回环服务，不调用在线转换。

8 个模板：散热筋机座、环筋机壳、轴承座端盖、锥形端罩、圆柱/圆环、空心锥台、阶梯法兰、带法兰端盖。全部是演示尺寸，不是自动读取参考照片的模型。

## 免费本地 AI 识图

已接入 Ollama 的本地视觉模型。当前 Mac 复用已安装的 `qwen3.5:35b-a3b-q8_0`，无需再次下载，无 API 调用费、不需密钥或云端账号。模型约 39 GB，模型文件不包含在工具压缩包内。硬件计算和电力仍由本机承担。

启动工具后，选择图纸图片，在“AI 自动建模”里点击 **AI 识别并计算**。首次加载和复杂图识别可能需要几分钟，页面显示实际等待时间。本地 Ollama 未运行时工具会尝试启动它；不会自动下载模型。默认仅调用 `127.0.0.1:11434`，绕过系统代理，并拒绝云端模型与不支持图片的模型。

识别结果包括回转段、局部筋/底脚/孔槽、原图尺寸依据、缺失信息和建模备注。尺寸齐全且通过校验时，在识图面板自动显示 **AI 草稿估重**。点击“载入草稿并编辑”可替换当前模型并继续逐段修改。AI 不直接给出重量，所有体积和重量由本工具的几何引擎计算。

信息不足、尺寸矛盾、未知尺寸或包含猜测时，不显示整件重量，也不能作为完整模型载入。可以在“补充尺寸或纠正识别”中输入可靠尺寸，再次识别；或者切换 OCR / 描点 / 手动建模。AI 能误读复杂工程图，草稿须对照原图核对，不能作为自动 CAD 还原或无需校核的生产依据。

换用另一款已安装的本地视觉模型时，启动前设置环境变量 `CASTING_VISION_MODEL` 为 Ollama 中的完整模型名。当前配置针对这台 Mac 的现有模型。服务日志在 `.runtime/server.log` 和 `.runtime/ollama.log`；使用版本更新后的启动器会验证并重启本项目旧服务。

官方资料：[Qwen3.5 本地视觉模型与许可](https://ollama.com/library/qwen3.5:35b-a3b-q8_0)、[Ollama 图片接口](https://docs.ollama.com/capabilities/vision)。

## OCR / 手动图纸工作流

1. 导入 PNG/JPG 等图片（不超过 15 MB / 2400 万像素），可旋转、放大和粘贴图片。PDF 请先导出所需图页。
2. 点击“识别尺寸标注”。本机 OCR 返回原文、位置和置信度。候选尺寸可映射到外径/内径/高度/Z。明确带“外径、内径、总长”等标签时自动填参数草稿。
3. 核对后勾选确认，选择新建或追加回转段，重量自动更新。新建会清除现有示例，追加会保留其余结构。复杂多段图纸不凭直径列表推断部位。
4. 不能直接拆分时，用“截面描点”：选已知距离两端并填写实际长度，再沿旋转轴正向选两点（第一点为共享 Z 原点），顺序描出一侧的闭合材料边界。可多块追加；所有区域使用相同轴线、原点和比例。
5. 仍无法识别的尺寸直接手动输入。没有内腔、壁厚或尺度信息的实物照片无法唯一确定重量。

后备方式为 **OCR 尺寸辅助 + 人工核对 / 描点**。AI 也无法保证理解任意复杂工程图或补齐缺失尺寸。透视照片不适合按像素精确描点，宜采用正投影图；圆弧用折线近似会产生误差。

参考照片括号外为毛坯、括号内为加工后尺寸（用户确认）。输入单位 mm，密度 g/cm³，结果 kg。默认密度 7.20 可调；切换口径会使 AI 草稿失效并更新 OCR 候选取值；须重新识图。已载入的模型尺寸不会自动替换，也不会自动加加工余量。
