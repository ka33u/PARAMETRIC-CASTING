# 参数化实体独立校验（2026-09-25）

42 / 42 组通过。最大相对体积差异 0.010040%，验收限值 0.15%。

## 校验方法

页面使用 Manifold 3.5.3 进行实体并集／切除，圆周离散为 256 段。独立校验使用 Open CASCADE 7.9.3.1（cadquery-ocp-novtk 7.9.3.1.1），根据每组原始参数重新创建精确曲面、实体和布尔关系，再计算 BRep 体积；未导入页面网格替代独立重建。全部通过 BRepCheck 实体有效性检查。

覆盖：18 种基础款式，6 类全结构组合，12 组缩放模型，以及实心锥台、浅端盖、薄壁环、小内孔筒体、无底盒体和筋厚覆盖值／孔洞组合 6 个边界案例。

构造树由同一参数规则提供，因此此校验能发现几何引擎、布尔运算和体积实现差异，但不能证明通用模板等同于用户的实际图纸。对原始尺寸和真实铸件的最终精度，仍取决于轮廓、壁厚、附属结构与材料密度；未建出的铸造圆角、拔模斜度、加工余量和浇冒口不含在结果中。

Shapr3D 已在本机发现，但原生自动化接口超时；没有取得商用软件测量结果。下列 STEP 文件由 OCCT 独立模型导出，可导入 Shapr3D、SolidWorks 等进一步人工核验；未声称已在这些软件中验证。

## 可审查文件

- `cases.json`：参数、构造树和页面引擎体积。
- `verification.json`：独立体积、相对差异、实体有效性及运行时长。
- 四个 STEP：`endcap-bowl.step`、`motor-axial.step`、`box-rounded.step`、`bracket-bracket.step`，单位 mm。

## 复算

需要 Node.js 及 Python 3.12。执行目录为项目根目录。

```sh
npm ci
npm test
python3.12 -m pip install --target solid-runtime cadquery-ocp-novtk==7.9.3.1.1
# 复算本报告固定案例；母模型在后续版本中已更新
python3.12 tools/verify_solids.py docs/三维校验/cases.json .runtime/solid-validation
```

浏览器计算器已打包 Manifold 与 Three.js，不要求安装上述校验环境。
