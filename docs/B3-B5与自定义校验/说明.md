# B3／B5 端盖与自定义组合校验（2026-09-26）

20 / 20 组通过独立 Open CASCADE 实体复算，全部实体有效，验收阈值为体积相对差 0.15%。本轮最大差约 0.03542%，出现在球体离散网格；这些数值是几何计算差异，不代表实际铸件的尺寸或估重精度。

## 端盖分类与图纸依据

只读查看了用户 Y2 图库的普通端盖毛坯图（8AGT.013.617M，HT200）与 B5 凸缘端盖毛坯图（8AGT.013.619M，HT200），用于识别壳体、轴承座、筋、耳和封闭端面的安装法兰。原始图纸与解析缓存不随工具包分发。本轮没有从这两张图完整恢复每一处尺寸、圆角和拔模斜度。

B3／B5 原为电机安装形式名称；本工具按用户习惯借用它们区分普通／法兰端盖。ABB 的安装形式资料将 B3 列为底脚安装、B5 列为大型法兰安装，可参见 [ABB 铸铁电机样本](https://library.e.abb.com/public/e66a5a81e80849fc8ac71fd0d4e31b7e/9AKK108196_General_performance_cast_iron_motors_09-2024_lowres.pdf)。这里对端盖模板的对应是结合图纸作出的结构分类，不是统一的标准端盖尺寸。

B3／B5 各验证圆筒壳、收口壳、平盘三种轮廓；B5 案例同时开启定位止口与法兰铸出孔。安装法兰位于封闭面，止口高度包含在总深度内。默认收口比例等细节仍是估重模板，需按具体图纸调整。

## 组合计算与覆盖

十二种基本形状分别复算；另有底板、圆环、圆周四孔以及圆周筋板的组合。所有加料求并集后统一减料，顺序无关；分项净体积相加等于完整实体体积。圆环截面采用折线近似，因此 CAD 复算比较的是同一输入轮廓；圆截面圆环的解析体积另有自动测试约束。

完整 JavaScript 回归为 117 / 117 项通过。新增用例覆盖解析体积、相交材料去重、重叠／外部孔、变换、直线与圆周排列、截面自交拒绝、JSON 往返、STL 体积、无效输入及旧方案兼容。

真实浏览器完成“底板＋圆环＋四孔”组合：180 × 150 × 12 mm 底板，D150／d80／H30 mm 圆环，四个 D12 mm 通孔；灰铸铁密度 7.2 g/cm³ 时显示 4.927 kg。保存刷新、删除撤销、红色减料体切换、JSON／STL／HTML 导出均通过；STL 封闭网格体积与页面计算一致。390 px 宽度下没有横向溢出。

## 复现

```sh
npm ci
npm test
node tools/make_custom_verification.mjs
python3 tools/verify_solids.py .runtime/custom-validation/cases.json .runtime/custom-validation
```

独立复算脚本需要可用的 OCP / Open CASCADE Python 环境；它不参与日常网页计算，也不包含在分发包中。本目录保存本轮 cases.json、verification.json 和三个 STEP 参考实体。浏览器采用 Manifold 的封闭三角网格，OCCT 根据同一几何树重新构建实体并测量体积；二者独立求解，但不能证明输入的尺寸与真实铸件完全一致。
