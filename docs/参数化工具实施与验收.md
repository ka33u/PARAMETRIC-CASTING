# 参数化铸件工具：实施与验收

本轮目标：主流程为选款式、修改少量参数、直接看到完整三维及重量。持续改进到实现与验证均满足要求；不以增加一组旧式表单代替。

## 完成条件

- 主页面提供端盖、机座、轴承盖、法兰／环件、接线盒／盖、底脚／支架等系列化母模型，每种常用主参数控制在 3～6 项。
- 筋、脚、耳、凸台、法兰、孔等选项可见，进阶尺寸按需展开；模板默认值与用户修改值可区分。
- 三维几何与计算同源：所有实际材料取并集，孔洞仅扣除与材料相交部分；非回转结构参与预览及体积。
- 毛坯为默认口径，未明确启用的加工孔不扣重。默认结构比例均标示为通用预设，不能伪称由 Y2／YE4 原图验证。
- 支持完整模型旋转、剖切、部位选择，尺寸变化即时重建；非法参数清除过期重量并给出可理解的原因。
- 可保存和复用参数化方案，修改尺寸后仍保留参数关系；可导出校验模型，保留旧版图纸工具入口。
- 本机启动和离线使用可用，依赖本地打包，不上传图纸。
- 独立三维几何验证覆盖各类母模型、结构组合、尺寸边界、交叠去重、孔洞；必须记录软件、参数、体积、误差和适用限制。
- 浏览器核验主流程、移动／窄窗布局、恢复方案、失效输入、导出及交互。不能只靠单元测试宣布完成。

## 验证选择

本机已查到 Shapr3D 与 Blender 5.0.1。Shapr3D 的原生自动化首次调用超时，尚无商用软件实测结果。优先继续使用本地可批量验证的几何工具；商用软件验证若未完成须如实列明。不得虚构整件铸造实物校准或误差承诺。

## 实现方向

由母模型生成显式实体构造树，再通过本地 Manifold 实体布尔生成封闭网格，渲染与重量均来自该几何。独立软件按同一尺寸重新构造实体进行比较，导入已有网格测体积只作为导出一致性验证，不代替独立建模验证。
