# 两端法兰独立轴向宽度校验（2026-09-26）

三种水冷模板均使用 A 端 20 mm、B 端 35 mm，同时开启底脚、底脚铸出孔、铸出水孔。3 / 3 组通过独立 Open CASCADE 实体与水套空腔复算，验收阈值 0.15%。

A 端位于模型轴向起点，B 端位于总长终点。法兰宽度沿轴向向机座内侧延伸，包含在总长内；外法兰不填充水套。封水环厚度另设。两端宽度之和不得超过总长。旧方案的 flangeT 自动迁移到 flangeAWidth 和 flangeBWidth，已有独立端部值优先保留。

自动回归另外验证：解析环形法兰体积、修改一端不影响另一端、总长与水套容积不变、边界尺寸拦截、两端相接不重复计重、参数往返和旧方案兼容。页面实测两个输入框、三维端部标记定位、三款切换、无效输入清空重量、刷新后恢复。
