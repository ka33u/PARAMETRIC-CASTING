# 水冷机座新增校验（2026-09-26）

18 / 18 组独立复算通过。最大铸件体积差 0.010040%，最大水套空腔体积差 0.010601%。验收阈值为 0.15%。本次只校验几何估重，不校验流量、压降、冷却性能、密封或铸造可制造性。

## 新模型定义

- 首页取消“底脚与支架”类别，新第六类为水冷机座。旧方案保留读取兼容，不再作为新建入口。
- 五个主尺寸：机座外径、定子腔内径、机座总长、内筒壁厚、外筒壁厚。水套径向净厚 = （外径 − 内径）/ 2 − 内筒壁厚 − 外筒壁厚。
- 三款：无隔筋的环形水套；轴向隔水筋（第一条全长，其余交替在两端留过水间隙）；环向隔水筋（过水窗口交替错开 180°）。均为整体同材质灰铸铁母模型，默认细节为模板比例。
- 计重实体包含内筒、外筒、封水环、隔水筋及已启用的底脚、法兰、水管座。所有结构取材料并集，孔仅扣交集。
- 水套净容积按水套范围减去实际铸件实体计算，已排除隔水筋；不包括接管、外接管路和冷却水重量。分体或异材外套需单独计重。
- 实心管座不扣后续加工水孔；显式选择“铸出水孔”才扣。穿孔深度止于水套，不穿过内筒进入定子腔。
- 全部材质封闭内腔的反向边界不被误算成额外铸件。半剖与蓝色水套显示不改变重量，也不把蓝色空腔写入铸件 STL。

## 校验方式

Manifold 3.5.3 以 256 段圆周创建页面实体。Open CASCADE 7.9.3.1 独立使用精确圆柱、拉伸、旋转和布尔重建同一尺寸的实体；对铸件和空腔分别进行 BRep 有效性检查与体积计算。构造关系来自同一母模型规则，因此不能以本比较证明模板符合某一张真实图纸。

包含三款默认、三款全结构组合及其 0.45 / 2.7 倍尺寸、0.5 mm 薄水套、短机座、不同内外壁厚、32 条轴向筋、12 道环向筋、裸双层筒体。附三款默认 STEP（单位 mm）、完整参数与构造树、逐项 JSON 结果。

```sh
node tools/make_water_verification.mjs
python3.12 tools/verify_solids.py .runtime/water-validation/cases.json .runtime/water-validation
```
